# FF14 絶コンテンツ攻略支援プラグイン 仕様書

## 概要

FF14の絶コンテンツ攻略を支援する、Dalamud上で動作する個人用プラグインの仕様書一式です。

戦闘ログを録画し、観測されたイベント（キャストID・ステータスIDなど）を素材にGUIで読み上げ・画面表示・安置位置指示などのトリガーを組み立てる、というワークフローを採用しています。

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `SPEC.md` | メイン仕様書 |
| `trigger-schema.json` | トリガー定義のJSONスキーマ |
| `trigger-samples/` | サンプルトリガー定義 |
| `trigger-samples/極エヌオー討滅戦.json` | 極エヌオー想定の基本サンプル |
| `trigger-samples/絶妖星乱舞.json` | 絶妖星乱舞想定の高度サンプル（フェーズ3機能含む） |
| `trigger-samples/sample-recording.jsonl` | 録画ログのサンプル（極エヌオー戦闘1回ぶん） |
| `roadmap.md` | 実装ロードマップ（MVP/フェーズ2/フェーズ3） |

## 読み進め方

1. **`SPEC.md`** を最初に読む。コンセプト・アーキテクチャ・全機能の仕様。
2. **`trigger-schema.json`** で定義フォーマットの詳細を確認。
3. **`trigger-samples/`** で実際のJSONがどう書かれるか把握。
4. **`roadmap.md`** で実装の進め方と優先度を確認。

## 開発の前提

- Claude Code を活用したC#開発
- Dalamud SDK
- 日本語クライアント前提

## 主な意思決定の記録

仕様策定の過程で行った主な意思決定：

- **トリガーフォーマット**: JSON（Claude Codeが書く前提）
- **MVP出力**: TTS + WAV + 中央テキスト + タイマーバー + チャットエコー
- **位置情報系もMVPに含む**: 絶コンテンツ実用のため
- **安置計算プリセット**: 全15種を実装、5形状のジオメトリ対応
- **状態変数・条件分岐**: フェーズ3で実装
- **録画**: コンテンツ単位で自動記録ON/OFF設定可能、デフォルトOFF
- **設定画面**: タイムラインビューと集計ビューの2モード
- **状態管理**: 設定済み/未設定/無視済みの3状態
- **ライブHUD**: ハイブリッド方式（タイムライン駆動 + sync補正）
- **言語**: 日本語のみ
- **スコープ外**: 自動回避・自動移動・自動スキル発動・画像認識
