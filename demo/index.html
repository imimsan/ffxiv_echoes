凡例
  • ボスキャスト

  • SyncPoint
  • Note（軽減/LB 等）
画面左上：次に来るイベント（アイコン + 残り秒数）。5 秒以内で黄色く点滅。
下のライブタイムライン：左 = 過去 10 秒、右 = 未来 30 秒、中央 = 現在。
使い方
  1. 戦闘開始 でクロックがスタート
  2. 左上の「次に来るイベント」にアイコン + カウントダウンが並ぶ（近いものほど上、5 秒以内で点滅）
  3. シミュレートされたボスキャストが時刻通りに走る
  4. マッチするトリガーが発火 → TTS + overlay_text + timer_bar
  5. Note は advance_warning_sec 秒前にも通知
  6. Role を変えると、role 指定のあるノートが半透明（自分宛てでない）になる
icon フィールド：絵文字（🛡 💪 💚 🔥 🎯 🔄 等）または画像 URL を指定できます。
実機の Dalamud プラグインと同等の挙動を CSS / JS で簡略再現したモックです。実装本体は src/FfxivEchoes/ 参照。
